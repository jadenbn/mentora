How to read every number on this page

One scale runs through the whole engine. A score rates one answered question from 0 to 1. Correct unassisted 1.0, correct with a hint 0.6, partial 0.3, wrong 0.0. That is score_attempt in engine/accuracy.py, and nothing else in the system is ever scored. Every other number on this page except course level averages those four values over a topic's last 8 attempts.

Two averages of those scores, and the gap between them is the point.

  • Observed ability. The raw mean, exactly what happened, or — before the first attempt. Read it, but note that the engine never decides on it. Two attempts and eight attempts read the same here.
  • Estimated ability. The same mean pulled toward a 0.50 no-evidence prior, so it always has a value and one lucky answer cannot swing it. estimated_accuracy adds 2 pseudo-observations at 0.5, so a student's own record starts to outweigh the prior around their 3rd real attempt. Selection acts on this one. It feeds the weakness term in pick_topic and sets the difficulty served next. A wide gap from the observed ability means the student has few attempts, nothing more.
  • The word under each bar is what the question generator is told for this topic's next question: introductory below 0.40, moderate below 0.70, challenging above. The generator never sees the number, only the word, and reads it relative to the topic. An untried topic sits at 0.50, so its first question is always moderate.
  • Course level is how advanced the topic is within the course, written by the model when it created the topic. It never changes and does not set question difficulty. Its only job is ordering: on a student's first question every topic ties, and the lowest course level is served first.
